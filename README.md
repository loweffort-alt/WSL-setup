# Welcome to my Linux Terminal Configuration!
This repository contains customized configurations for a complete development environment, including Neovim, Fish, Tmux, Zellij, and Alacritty. Windows users must install WSL2 to use this configuration.
## Installing Package Manager
I use homebrew to install packages so you need to install it first. You can install it by running the following command:
```bash
sudo apt-get update
sudo apt-get upgrade
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
